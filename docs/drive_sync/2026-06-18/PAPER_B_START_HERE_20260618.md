## Paper B 현재 초점

Paper B는 Paper2 consensus/reference standard와 analysis-ready input/output 확인이 중심입니다. 현재 공유한 묶음은 다음 계열입니다.

- Human final consensus reference standard
- Direct-r construct pair / study summary / numeric QC
- Unified consensus decisions and metadata
- R2/R3 consensus correlation analysis inputs
- consensus integration queue/status
- evidence inventory and human review comments inventory

## Paper B 요구사항

1. Paper B 파일은 Paper2 consensus와 analysis input/output 기준으로 확인합니다.
2. Paper A Track Changes 원고 수정 요구사항은 이 폴더에서 다루지 않습니다.
3. source-derived consensus와 scoring/analysis denominator는 섞어 쓰지 않고, 파일명과 manifest 기준으로 확인합니다.
4. Paper B 상태 변경은 status/manifest 문서에 먼저 남깁니다.
