# Paper C Scripts

Future scripts should support:

- Corpus manifest validation.
- JSON schema validation for raw Codex and LongTable outputs.
- Three-way `H-C-L` comparison table generation.
- Error taxonomy coding support.
- Auditability metric calculation.
- Repeated-run stability summaries.

Scripts must not assume private PDFs or raw model transcripts are committed to
Git. Use manifest paths and environment-specific local inputs.
