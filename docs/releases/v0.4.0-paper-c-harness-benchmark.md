# v0.4.0 - Paper C Harness Benchmark Scaffold

Release date: 2026-05-10

## Summary

This release establishes Paper C as a separate computational evaluation of a
stateful LLM extraction harness. The study is now scoped around a same-model
comparison of frozen human reference values (`H`), raw Codex outputs (`C`), and
Codex + LongTable harness outputs (`L`) across the full 213-study Paper B
validation corpus.

## Primary Target

JMIR Metascience and Research Integrity.

## Added

- `paper_c/` study scaffold:
  - Research specification.
  - Protocol.
  - Analysis plan.
  - Measurement plan.
  - Journal strategy.
  - Literature-review map.
  - Prompt, schema, script, and template folders.
- `data/04_extraction/07_paper_c_harness_benchmark/` benchmark workspace:
  - Corpus manifest area.
  - Human reference snapshot area.
  - Raw Codex output area.
  - Codex + LongTable output area.
  - Three-way comparison area.
  - Auditability metrics area.

  - Local-only private artifact area.

- Corpus manifest and three-way comparison CSV templates.
- Decision log fixing the Paper C journal target, corpus, comparison design,
  and minimum LongTable artifact set.

## Changed

- `AGENTS.md` now preserves the Paper B reference-standard workflow gate while
  adding Paper C harness-benchmark guidance.
- `.gitignore` now excludes local LongTable runtime state, `CURRENT.md`, local
  OMX state, and private Paper C benchmark artifacts.

## Not Included

- No final Paper C extraction results.
- No raw model transcripts.
- No private `.longtable/` state.
- No raw PDFs or private human coding workbooks.
- No final LLM accuracy analysis, because the frozen human reference standard
  must exist first.
