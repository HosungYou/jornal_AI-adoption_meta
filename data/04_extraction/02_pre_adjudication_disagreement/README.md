# Step 2: Pre-Adjudication Human-Human Disagreement

Use this folder for pairwise comparison workbooks and disagreement summaries
generated from frozen raw human coder data.

This step answers what humans disagreed about before consensus or adjudication.
It is analytically separate from the adjudicated reference standard.

Required summaries:

- Disagreement by phase and pair
- Disagreement by extraction family
- Numeric difference distributions for r, beta, N, and reliability values
- Construct-mapping disagreement list
- Fields requiring source-document adjudication
