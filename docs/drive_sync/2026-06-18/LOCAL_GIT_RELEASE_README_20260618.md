# Local Git Release Package

This Git package records the 2026-06-18 Drive synchronization and Paper A/B split.

## What Is Included

- Drive workflow and collaboration README files
- Paper A and Paper B start-here documents
- OneDrive to Google Drive structure audit
- File-count and size manifests
- Verification logs

## What Is Not Included

The full 4.3GB OneDrive/Google Drive research corpus is not committed to Git. Large source files, PDFs, archives, and working Office files remain in OneDrive and Google Drive.

## Why

GitHub is the release ledger. OneDrive and Google Drive are the file stores. This keeps release history reviewable without duplicating or corrupting the working research archive.
