## Required Order

1. Freeze assignment log before coding starts.
2. Complete independent human coding with LLM outputs blinded.
3. Generate pairwise discrepancy tables.
4. Analyze raw human-human disagreement.
5. Adjudicate against the source documents.
6. Freeze the source-anchored adjudicated human reference.
7. Open LLM outputs only after the reference freeze.
