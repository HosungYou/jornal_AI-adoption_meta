# Quality Assurance Records

This folder is reserved for QA gates, spot-check summaries, and validation logs
after the Phase 1 and Phase 2 reference data are frozen.

## QA Blocks

- Range checks for r, beta, reliability, and sample size values.
- Matrix completeness and symmetry checks.
- Duplicate study/sample checks.
- Phase and pair-level anomaly review.
- Post-adjudication correction log.

QA does not replace adjudication. It checks whether the frozen reference and
analysis inputs are internally coherent before MASEM and LLM substitution
analyses are run.
