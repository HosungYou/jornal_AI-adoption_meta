# Paper A public repository package, 2026-06-15

This is a share-safe OSF-ready package for Paper A.

## Contents

- `1_Manuscript/`: current manuscript draft and inline APA7 Word draft.
- `2_Aggregate_Results/`: aggregate MASEM fit/path tables and supplemental diagnostics.
- `3_Figures/`: original Paper A figures generated from project data.
- `4_Scripts/`: scripts used to generate supplemental diagnostics and manuscript outputs.
- `5_Reference_Review_Manifest/`: manifest and review notes for locally reviewed reference PDFs.

## Excluded by design

- Raw PDFs are not redistributed.
- Raw coder workbooks and private extraction files are not redistributed.
- Closed-source institutional PDFs are not redistributed.
- Runtime files from `.longtable/` and `.omx/` are not redistributed.
