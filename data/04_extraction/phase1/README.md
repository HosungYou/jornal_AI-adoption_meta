# Phase 1 Human Coding

Phase 1 is the completed Wave 1 human coding block for the Paper B validation
corpus.

## Scope

- Pair A: R1 + R2
- Pair B: R3 + R4
- Study count: 100
- Status: independent coding complete; pairwise comparison and adjudication
  artifacts are maintained in `../consensus/`

## Data States

Keep these states separate:

- Raw independent coder values before consensus.
- Pairwise difference tables.
- Source-anchored adjudicated human reference values.

Raw coder values should not be overwritten during adjudication.

## GitHub Handling

Track share-safe documentation, scripts, and comparison artifacts. Do not track
machine-specific PDFs, Excel lock files, or private raw files that should remain
local only.
