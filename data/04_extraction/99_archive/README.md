# Archive

This folder holds historical extraction-related files that are not part of the
active five-step workflow.

Archived files are retained for traceability only. Do not use them as current
inputs unless a newer workflow document explicitly promotes them back into an
active numbered folder.

## Contents

- `old_coder_versions/R4/`: Earlier R4 workbook snapshots. The active R4 Phase 1
  raw workbook is the 2026-04-23 version promoted to
  `../01_raw_human_coder_data_freeze/phase1/coder_packages/R4/AI_Adoption_MASEM_Coding_v3_R4.xlsx`.
- `annotated_guides/`: Coder-specific guide copies that are no longer canonical.
- `progress_logs/`: Historical progress notes superseded by the active workflow
  status log.
- `screening_support/`: Screening-support files that are not active extraction
  inputs.
- `source_pdf_variants/`: Local-only source PDF variants that were not promoted
  as the active `S###.pdf` file.
